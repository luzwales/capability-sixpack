# Data and DMAIC

## The DMAIC Roadmap

Lean Six Sigma offers a roadmap known as **DMAIC** (D-M-A-I-C)—five phases prescribing a stepwise procedure for process improvement.

### Core Principles

- Based on **measurements**
- Uses **evidence-based improvement actions**
- **Data and data analysis** is critical in any DMAIC project

> Someone leading a Lean Six Sigma project is called a **Belt**. You can lead a Black Belt or Green Belt project, depending on complexity and size.

---

## The Five DMAIC Phases

| Phase | Letter | Focus |
|-------|--------|-------|
| Define | D | Select project and establish objectives |
| Measure | M | Quantify the problem and measure process performance |
| Analyze | A | Analyze current situation and diagnose |
| Improve | I | Develop and implement improvement actions |
| Control | C | Improve process controls and close project |

---

## Define Phase

The belt **selects a project** and **establishes project objectives**.

This phase sets the foundation for everything that follows.

---

## Measure Phase

The belt makes the problem **quantifiable** and measures **process performance**.

> "You cannot improve what you cannot measure."

### Useful Techniques

- **Pareto analysis** — Focus on the biggest problems
- **Sampling strategies** — Select which observations to include in measurement

---

## Analyze Phase

The belt analyzes the **current situation** and makes a **diagnosis**.

**Goal:** Determine the nature of the problem at hand.

### Useful Techniques

- **Histograms** — Visualize data distribution
- **Pie charts** — Show proportional breakdowns
- **Specification analysis** — Determine percentage of cases within specifications

---

## Improve Phase

After diagnosis, the belt **develops and implements improvement actions** based on vital influence factors.

**Critical:** The effectiveness of proposed improvement actions must be demonstrated first.

### Useful Techniques

- **Scatter plots** — Show relationships between variables
- **Box plots** — Compare distributions across groups
- **Regression** — Prove statistical relationships
- **ANOVA** — Show variables have significant relationships

---

## Control Phase

The belt **improves process controls** and **closes the project**.

> This is vital—we don't want the process to slip back to its performance level before the improvement.

### Useful Techniques

- **Two-sample t-test** — Compare before and after project situation to show effectiveness

---

## Data Analytics Across DMAIC

| Phase | Data Analytics Purpose |
|-------|------------------------|
| **Measure** | Collect measurements |
| **Analyze** | Analyze current performance |
| **Improve** | Verify effectiveness of improvement actions |
| **Control** | Quantify project results |

---

## Summary

- **DMAIC** is the five-phase roadmap for Lean Six Sigma projects
- Project leaders are called **Belts** (Black Belt or Green Belt)
- Each phase has specific **data tools and techniques**:
  - Define: Project selection and objectives
  - Measure: Pareto analysis, sampling strategies
  - Analyze: Histograms, pie charts, specification analysis
  - Improve: Scatter plots, box plots, regression, ANOVA
  - Control: Two-sample t-test for before/after comparison
- **Data analytics** is essential throughout the entire DMAIC cycle
